# Issue Tracker

Use this folder for actionable project issues that should persist beyond a
single feature checklist. Keep one Markdown file per category:

- [Security issues and hardening](./security-issues.md) — vulnerabilities and
  security risks, including deployment-specific hardening.
- [Functional issues](./functional-issues.md) — user-visible defects and
  active investigations.
- [Technical debt](./technical-debt.md) — maintainability and verification
  work.

Give each issue a stable category-prefixed ID, status, priority, concise
impact, and next action. Update the entry when its status changes; avoid
duplicating the full issue report in feature documents. Keep secrets,
personal data, raw tokens, and sensitive production details out of these
files.
